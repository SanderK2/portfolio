## About Naturity
Naturity was a personal project I had before starting my studies at NTNU. It envolved creating a website and webstore functionality for the cosmetic company Naturity. The application was built with Next.js and integrates the Shopify API so that the users are able to purchase products directly from within the website. The website also features an about page, contact page, store locations page, and a Blog, where the owner is easily able to create blog posts for customers that seek more information about the products and other tips and tricks. The project was in active use and recieved paying customers in the course of 2 years, from the start of 2022 to the end of 2023.
