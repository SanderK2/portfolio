## About Studyfront
Studyfront is a web application that was developed as part of the Webproject course. It is made to give researchers a tool to create and perform comparative studies. It is built with Next.js and has features like creating, starting, and completing studies, getting information about the participant, and add time limits to the studies. Researchers have the option to add up to 7 different components to the study, like rating scale, checkboxes, multiple choice etc. Researchers can then export the results of the studies in both .csv and .json-fileformats.
